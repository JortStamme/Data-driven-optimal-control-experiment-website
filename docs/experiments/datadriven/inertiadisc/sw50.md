# Inertia Disc: \(50^\circ\) Square Wave Tracking

All six controllers (D1 and D2 × Direct noise-free, Direct noisy, and Indirect LS) are tested on a \(50^\circ\) square wave at \(0.125\text{ Hz}\) (\(24\text{ s}\), metrics averaged over five full swings, \(0\%\) saturation).

### Observations & Metrics (Table C.6)
* Five controllers immediately break stiction and track cleanly (\(t_s = 1.50\text{--}2.16\text{ s}\), \(\text{OS} \le 0.34^\circ\)).
* **D2 Direct, noisy** is fastest (\(t_s = 1.50\text{ s}\)), while **D2 Direct, noise-free** and **D2 Indirect (LS)** produce virtually identical trajectories, confirming Proposition 3.30 on hardware.
* **D1 Direct, noisy** suffers severe underdamped overshoot (\(\text{OS} = 85.0^\circ\), peaking near \(\pm 200^\circ\)) due to gain attenuation (\(\rho_{\text{LS}} = 0.9973\)).

<!-- Unified JavaScript function for all synchronized videos on this page -->
<script>
  function syncPlayPause(id1, id2) {
    var v1 = document.getElementById(id1);
    var v2 = document.getElementById(id2);
    if (v1.paused) { v1.play(); v2.play(); }
    else { v1.pause(); v2.pause(); }
  }
  function syncRestart(id1, id2) {
    var v1 = document.getElementById(id1);
    var v2 = document.getElementById(id2);
    v1.currentTime = 0; v2.currentTime = 0;
    v1.play(); v2.play();
  }
</script>
